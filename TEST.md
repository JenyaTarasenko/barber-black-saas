Напиши полные тесты для API слоя приложения accounts/ (serializers, views, urls).

Файловая структура тестов:
Создай или обнови файлы в apps/accounts/tests/:
- test_serializers.py
- test_views.py
- test_urls.py

Требования к тестам:

1. test_serializers.py:
   - Проверка валидации корректных данных при регистрации и изменении профиля.
   - Проверка ошибок валидации (некорректный email, дублирование email, короткий/слабый пароль).
   - Проверка write_only полей: убедись, что пароль (password) присутствует во входящих данных, но НИКОГДА не возвращается в итоговом serialized.data.

2. test_views.py (используй rest_framework.test.APITestCase):
   - POST /api/accounts/register/: успешная регистрация (HTTP 201 Created), создание записи в БД, хеширование пароля (проверить, что пароль не лежит открытым текстом), обработка ошибок 400 Bad Request при неверных данных.
   - GET /api/accounts/me/: успешный получение своего профиля авторизованным пользователем (HTTP 200 OK), отказ в доступе неавторизованному пользователю (HTTP 401 Unauthorized).
   - PUT/PATCH /api/accounts/me/: обновление полей first_name, last_name, phone.
   - POST /api/accounts/change-password/: успешная смена пароля с правильным старым паролем, ошибка 400 при неверном старом пароле.

3. test_urls.py:
   - Проверка реверсинга URL-адресов (django.urls.reverse) для всех name в accounts: 'register', 'me', 'change-password' (а также 'token_obtain_pair' и 'token_refresh', если они подключены).
   - Проверка соответствия URL-путей нужным View-классам (django.urls.resolve).

Обязательное условие:
После написания кода запусти тесты командой `python manage.py test apps.accounts` и убедись, что все тесты проходят (OK). Если возникнут ошибки — сразу исправь их.
