запрос для тестирования backend.models
Проанализируй файл apps/schedules/models.py.

1. Напиши исчерпывающие unit-тесты для всех моделей из apps/schedules/models.py, чтобы обеспечить максимально возможное покрытие кода (создание объектов, связи, ограничения, дефолтные значения, методы __str__, валидации).
2. Сохрани все тесты в файл apps/schedules/tests/test_models.py (или apps/schedules/tests.py, если структуры с папкой tests нет).
3. Запусти их через консоль командой:
   python manage.py test apps.schedules

СТРОГИЕ ПРАВИЛА:
- Исходный код проекта (включая файлы моделей в apps/schedules/models.py) менять КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО.
- Если тесты упадут с ошибкой, корректируй ТОЛЬКО сам файл тестов под существующее поведение моделей и перезапускай команду, пока абсолютно все тесты не пройдут успешно.
- После выполнения выведи отчёт с результатами запуска и итоговым процентом покрытия.
