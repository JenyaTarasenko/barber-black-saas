Напиши комплексные тесты производительности базы данных для ВСЕХ приложений проекта (apps/*). 

Требования к выполнению:

1. Создай базовый тестовый класс DatabasePerformanceTestCase (например, в apps/core/tests/base.py или utils):
   - Используй Django TestCase / APITestCase.
   - Используй self.assertNumQueries() для проверки N+1 проблем в сервисах и API ViewSets.

2. Для КАЖДОЙ модели и ViewSet/QuerySet во всех приложениях добавь тесты:
   - Проверка списочных эндпоинтов (List API): создание 20+ записей и проверка, что количество SQL-запросов фиксировано и не растет с ростом количества объектов (правильное использование select_related и prefetch_related).
   - Проверка bulk-операций: тестируй создание и обновление через bulk_create и bulk_update, а не цикл с save().
   - Проверка тяжелых агрегаций и фильтраций.

3. Запусти написанные тесты, найди места, где возникли лишние N+1 запросы в коде проекта, и сразу исправь их (добавь нужные select_related/prefetch_related в queryset).

4. Выполни итоговый прогон тестов командой:
   python manage.py test --tag=performance
