# Appointment Rules

1. Appointment принадлежит одному Salon.

2. Employee должен принадлежать этому Salon.

3. Client должен принадлежать этому Salon.

4. Branch должен принадлежать этому Salon.

5. Employee должен работать в выбранном Branch.

6. Employee должен оказывать выбранную Service.

7. Время записи не должно пересекаться
   с другой записью Employee.

8. Appointment не может быть создан
   вне рабочего времени Employee.

9. Appointment не может попасть
   в ScheduleBreak.

10. Отменённая запись не блокирует время.
